# geometric_lib

## Общее описание

`geometric_lib` — небольшая библиотека на Python для подсчёта площади и периметра
простых геометрических фигур. Сейчас в ней две фигуры: круг и квадрат.
Каждая фигура лежит в отдельном модуле, в каждом модуле есть две функции —
`area` (площадь) и `perimeter` (периметр).

Подключение:

```python
import circle
import square
```

## Функции

### circle.py

#### `area(r)`

Площадь круга по радиусу `r`. Формула: S = πR².

```python
>>> circle.area(2)
12.566370614359172
```

#### `perimeter(r)`

Длина окружности (периметр круга) по радиусу `r`. Формула: P = 2πR.

```python
>>> circle.perimeter(2)
12.566370614359172
```

### square.py

#### `area(a)`

Площадь квадрата по длине стороны `a`. Формула: S = a².

```python
>>> square.area(5)
25
```

#### `perimeter(a)`

Периметр квадрата по длине стороны `a`. Формула: P = 4a.

```python
>>> square.perimeter(5)
20
```
